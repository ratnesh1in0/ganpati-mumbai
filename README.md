## 🌟 Key Features

- **🔴 Live Crowd & Queue Tracker**: Real-time wait times for Charan Sparsh, Mukh Darshan, and general queues across iconic mandals with crowdsourced devotee verification.
- **🗺️ Interactive Illuminated Darshan Map**: Built with Leaflet & OpenStreetMap, displaying live crowd heat glows, metro/local train stations, and fast GPS centering.
- **🚶 Curated Walkable Circuits**: Time-optimized trails like *Lalbaug Trinity* (Lalbaugcha Raja + Ganesh Galli + Chinchpokli Chintamani), *South Mumbai Heritage 1893*, *GSB Divine Gold*, and *Midnight to Dawn 24x7*.
- **🧭 Custom Route Builder**: devises custom multi-mandal itineraries with automatic distance and walking time estimates.
- **🚆 24x7 Suburban Trains & Transit Guide**: Night local train timetables (Central, Western, Harbour), 20+ designated parking grounds, and Mumbai Traffic Police road closure advisories.
- **📹 24x7 Live Darshan Feeds**: HD multi-stream player for Lalbaugcha Raja, Chinchpokli, and GSB with live countdowns to daily Aartis.
- **🌊 Visarjan Beach & Artificial Lake Guide**: Immersion spots for Girgaon Chowpatty, Juhu Beach, Dadar Chowpatty, and 200+ BMC eco-friendly artificial lakes with high-tide timings.
- **🔔 Aarti Sangrah with Temple Bell (घंटा नाद)**: Devotional prayer reader (Marathi & English) featuring a synthesized Web Audio Vedic brass temple chime.
- **🌐 100% Dual Language (मराठी / English)**: Instant one-click toggle between authentic Marathi and English.
- **🔒 Privacy First & 100% Non-Commercial**: Zero ads, zero trackers, zero monetization. Devotee location stays exclusively in the browser.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Bundler**: Vite 8 with `@tailwindcss/vite` (Tailwind CSS v4)
- **Styling**: Tailored devotional palette (`--raat: #14100C`, `--shendur: #E2621B`, `--pital: #E5A93C`, `--zendu: #F59E0B`, `--chandan: #F5EBE1`)
- **Maps**: Leaflet + React Leaflet
- **Icons**: Lucide React + Custom Devotional SVG Glyphs
- **Audio**: Web Audio API (Physical harmonic brass temple bell)
- **Effects**: Canvas Confetti

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/<your-username>/ganpati-mumbai.git
cd ganpati-mumbai
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start development server
```bash
npm run dev
```
Open `http://localhost:5173` in your browser.

### 4. Build for production
```bash
npm run build
npm run preview
```
